# Dokumentasi Rentaid

Pilih panduan sesuai kebutuhan:

| Pembaca                    | Mulai dari                                | Isi                                                                                         |
| -------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------- |
| Penyewa, vendor, dan admin | [Panduan pengguna](users/README.md)       | Akun, katalog, sewa, pengelolaan toko, pesanan, serta [Android](users/android.md).          |
| Business owner             | [Gambaran bisnis](business/README.md)     | Cakupan MVP, peran, nilai transaksi, dan [aturan bisnis kanonik](business/rules.md).        |
| Software architect         | [Arsitektur](architecture/README.md)      | Batas aplikasi, data, keamanan, kontrak, dan [keputusan teknis](architecture/decisions.md). |
| Software engineer          | [Panduan engineer](engineering/README.md) | Setup, development, testing, build, demo, backup, dan pemulihan.                            |

Riwayat phase dan hasil lampau ada di [arsip migrasi](archive/migration-plan.md) dan [progres MVP](archive/migration-progress.md). Hasil bertanggal mencatat pengujian pada saat itu.
