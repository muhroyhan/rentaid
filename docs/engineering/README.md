# Panduan software engineer

Mulai dari [pengembangan lokal](development.md) untuk toolchain, PostgreSQL, API, marketplace, admin, konfigurasi, kontrak, dan build. [Pengujian](testing.md) menjelaskan kategori, prasyarat, data terisolasi, serta runner lintas aplikasi.

Untuk demo Compose dan pemulihan, gunakan [demo dan backup/restore](demo.md). Untuk skenario gangguan dan hasil historis, lihat [stabilitas](stability.md). [Panduan Android](../users/android.md) mencakup pemasangan dan koneksi perangkat/emulator.

[Instruksi Codex](agents.md) menjelaskan aturan root, modul audit/testing/docs, instruksi per aplikasi, dan cara memeriksa penemuannya.

Sebelum mengubah aturan, baca [aturan bisnis kanonik](../business/rules.md). Sebelum mengubah API, baca [arsitektur dan kontrak](../architecture/README.md). Kode, identifier, dan pesan commit memakai bahasa Inggris; panduan pengguna dan operasional memakai Bahasa Indonesia.
